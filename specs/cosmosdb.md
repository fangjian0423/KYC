# Module Specification: Cosmos DB Data Access Layer
# Purpose: State store and polymorphic JSON data repository for Case Management.

[METADATA]
Target_Runtime: Node.js (TypeScript) / Express Backend
Azure_Service: Azure Cosmos DB (SQL/NoSQL API)
Security_Mode: PoC (Connection String Auth - No IAM/Entra)

[DATABASE CONFIGURATION]
Database_Name: KycCaseManagement
Collection_Name: Cases
Partition_Key: /id

[DOCUMENT SCHEMA SPECIFICATION]
The collection must support a single, polymorphic document schema reflecting the progressive workflow states of the agents:

{
  "id": "string (UUIDv4 generated by backend)",
  "status": "string (SUBMITTED | EXTRACTION_COMPLETE | UBO_COMPLETE | VERIFIED | DISCREPANCY_FOUND)",
  "companyName": "string",
  "countryCode": "string (ISO-2)",
  "createdAt": "string (ISO8601 Timestamp)",
  "updatedAt": "string (ISO8601 Timestamp)",
  "documents": [
    {
      "docId": "string",
      "fileName": "string",
      "docType": "string (PASSPORT | BUSINESS_REGISTRATION | BANK_STATEMENT)",
      "blobUrl": "string"
    }
  ],
  "extractedData": {
    "registrationNumber": "string",
    "legalName": "string",
    "documentTypeIdentified": "string",
    "shareholders": [
      {
        "name": "string",
        "equityPercentage": "number"
      }
    ]
  },
  "uboRegistryData": {
    "registryName": "string",
    "taxCode": "string",
    "shareholders": [
      {
        "name": "string",
        "equityPercentage": "number"
      }
    ]
  },
  "comparisonResults": {
    "matchScore": "number (0-100)",
    "discrepancies": [
      {
        "field": "string",
        "extractedValue": "string",
        "registryValue": "string",
        "severity": "string (CRITICAL | WARNING)"
      }
    ]
  }
}

[REQUIRED COPILOT OUTPUTS]
1. An Azure Cosmos DB Client Initializer using `@azure/cosmos` driven via process.env.COSMOS_CONNECTION_STRING.
2. A Repository Class (`CaseRepository`) providing the following async functions:
   - `createCase(companyName: string, countryCode: string, documents: Array): Promise<Case>`
   - `getCaseById(id: string): Promise<Case>`
   - `updateAgentState(id: string, section: 'extractedData' | 'uboRegistryData' | 'comparisonResults', data: any, nextStatus: string): Promise<Case>`
   - `getActiveCases(): Promise<Array<Case>>`
